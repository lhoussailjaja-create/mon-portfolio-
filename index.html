Importer un relevé PDF

Le PDF Wafa Bourse est la source d’entrée. L’application met à jour le Portfolio, le Journal et le classeur Excel automatiquement.

1. Importer le relevé PDF — étape principale

Choisissez le relevé Wafa Bourse depuis Fichiers sur iPhone, iPad ou ordinateur. Le relevé Historique du compte alimente le Journal uniquement. Le relevé Titres / Positions alimente les positions. La Synthèse du portefeuille actualise le total comptable, les espèces et la valorisation datée. Excel est actualisé après validation.

Choisissez le bon type de relevé : Historique du compte pour le Journal ; Relevé Titres / Positions pour les quantités, cours, PRMP et valorisations. Un historique seul ne contient pas les données nécessaires aux Positions. Les doublons sont ignorés et Excel est actualisé après validation.

Ou utiliser le Copier-Coller

2. Excel ↔ Portfolio — synchronisation et sauvegarde

Cette fonction est secondaire : utilisez-la pour réimporter un classeur Excel déjà existant ou restaurer une sauvegarde. Elle ne conditionne pas l’importation PDF.

Aucun classeur analysé.

La synchronisation ne supprime aucune donnée locale. Les doublons sont ignorés grâce à la clé anti-doublon. Vérifiez le résumé avant validation.

Règles d’importation

  • Lecture selon les intitulés des colonnes, même si leur ordre change.
  • Actions et OPCVM restent séparés.
  • La valorisation et le +/- latent sont conservés tels qu’affichés dans le PDF.
  • Les champs absents restent vides, jamais remplacés par zéro.
  • Les lignes déjà présentes sont mises à jour par nom ; les autres positions sont conservées.
  • Le tableau fiscal et les frais ne sont pas confondus avec les pertes latentes.

Important

Cette méthode importe le texte sélectionnable du PDF. Si le PDF est une image/scanné et que le texte ne peut pas être sélectionné, il faudra d’abord utiliser la fonction « Copier le texte » ou l’OCR de l’appareil.

Vérifiez toujours l’aperçu avant validation. Seules les lignes effectivement détectées seront importées.
