MON PORTFOLIO V26 — INSTALLATION SUR IPHONE

1) Créer un dépôt GitHub privé.
2) Envoyer tous les fichiers de ce dossier, en gardant .github/workflows/pages.yml.
3) Activer GitHub Pages avec GitHub Actions si demandé.
4) Ouvrir l'URL Pages dans Safari.
5) Safari → Partager → Sur l'écran d'accueil → Ajouter.

IMPORTANT
- Cette version ne contient pas le snapshot personnel du portefeuille.
- Les données sont importées avec « Importer Backup » dans l'application.
- Ne mets jamais ton identifiant ou mot de passe Wafa Bourse dans le fichier.
