MON PORTFOLIO V28 — VERSION SANS DONNÉES PERSONNELLES

- Aucun montant, titre ou relevé personnel n'est préchargé.
- Les données saisies dans l'application sont stockées localement sur l'appareil.
- Backup permet de transférer les données entre tes appareils.
- Le bouton « Effacer les données locales » supprime les données V28 de l'appareil.

IMPORTANT :
GitHub Pages est public. Cette version évite d'exposer les données personnelles dans le code publié, mais le site lui-même reste accessible publiquement.
